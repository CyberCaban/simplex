# Симплекс-метод - Решение задач линейного программирования

Веб-приложение для решения задач линейного программирования симплекс-методом и методом искусственного базиса.

## 🚀 Возможности

- ✅ Решение задач ЛП симплекс-методом
- ✅ Метод искусственного базиса (двухфазный метод)
- ✅ Автоматический и пошаговый режимы решения
- ✅ Выбор опорного элемента в пошаговом режиме
- ✅ **НОВОЕ:** Навигация между шагами в обоих режимах (вперед/назад)
- ✅ Работа с обыкновенными и десятичными дробями
- ✅ Сохранение и загрузка задач из файла
- ✅ **НОВОЕ:** Загрузка готовых примеров из библиотеки (6 примеров)
- ✅ Интерактивные симплекс-таблицы
- ✅ **НОВОЕ:** Визуализация всех промежуточных шагов во всех режимах
- ✅ **НОВОЕ:** Улучшенные сообщения об ошибках с подробным описанием
- ✅ Встроенная справка и контекстная помощь
- ✅ Валидация входных данных
- ✅ Размерность задач до 16×16

## 📋 Требования к задаче

Программа работает с задачами в **канонической форме**:

```
f(x) = c₁x₁ + c₂x₂ + ... + cₙxₙ → min (или max)

При ограничениях:
a₁₁x₁ + a₁₂x₂ + ... + a₁ₙxₙ = b₁
a₂₁x₁ + a₂₂x₂ + ... + a₂ₙxₙ = b₂
...
aₘ₁x₁ + aₘ₂x₂ + ... + aₘₙxₙ = bₘ

xᵢ ≥ 0, i = 1..n
```

## 📖 Использование

### Быстрый старт

1. **Укажите размерность задачи**
   - Количество переменных (2-16)
   - Количество ограничений (2-16)

2. **Введите целевую функцию**
   - Коэффициенты при переменных
   - Выберите тип оптимизации (min/max)

3. **Введите ограничения**
   - Коэффициенты системы уравнений
   - Правую часть (свободные члены)

4. **Выберите способ задания базиса**
   - Вручную (если знаете допустимый базис)
   - Метод искусственного базиса (автоматический поиск)

5. **Выберите режим решения**
   - Автоматический - полное решение за один клик
   - Пошаговый - контроль каждого шага с выбором опорного элемента

### Форматы ввода чисел

- Целые числа: `1`, `-2`, `5`
- Обыкновенные дроби: `1/2`, `-3/4`, `2/3`
- Десятичные дроби: `0.5`, `-0.75`, `1.25`

### Работа с файлами

#### Сохранение задачи
```
Кнопка "Сохранить в файл" → задача сохраняется в формате JSON
```

#### Загрузка задачи
```
Кнопка "Загрузить из файла" → выбор JSON файла → восстановление всех параметров
```

Формат файла:
```json
{
  "numVariables": 2,
  "numConstraints": 2,
  "isMaximization": false,
  "fnCoeffs": ["1", "1"],
  "constraints": [
    ["1", "1", "4"],
    ["1", "-1", "2"]
  ],
  "basis": [true, true],
  "useArtificialBasis": false
}
```

## 🎯 Примеры задач

### Пример 1: Простая задача минимизации

```
f(x) = x₁ + x₂ → min

Ограничения:
x₁ + x₂ = 4
x₁ - x₂ = 2
xᵢ ≥ 0
```

**Ввод в программу:**
- Переменных: 2
- Ограничений: 2
- Целевая функция: `1`, `1`, тип: `min`
- Ограничение 1: `1`, `1`, `4`
- Ограничение 2: `1`, `-1`, `2`
- Базис: x₁, x₂

### Пример 2: Задача с дробями

```
f(x) = 1/2·x₁ + 3/4·x₂ → max

Ограничения:
2·x₁ + x₂ = 10
x₁ + 2·x₂ = 8
xᵢ ≥ 0
```

**Ввод в программу:**
- Переменных: 2
- Ограничений: 2
- Целевая функция: `1/2`, `3/4`, тип: `max`
- Ограничение 1: `2`, `1`, `10`
- Ограничение 2: `1`, `2`, `8`
- Использовать метод искусственного базиса

## 🎨 Особенности интерфейса

### Автоматический режим
- Полное решение с одним кликом
- История всех шагов в раскрывающихся блоках
- Каждый шаг содержит симплекс-таблицу и описание
- **НОВОЕ:** Навигация между шагами с помощью кнопок ← →
- **НОВОЕ:** Возможность вернуться к любому шагу

### Пошаговый режим
- Интерактивный выбор опорного элемента
- Подсветка возможных опорных элементов (синий цвет)
- Подсветка выбранного элемента (зеленый цвет)
- Навигация между шагами кнопками ← →
- Счетчик текущего шага
- **НОВОЕ:** Работает с методом искусственного базиса
- **НОВОЕ:** Полная история с возможностью просмотра любого шага

### Симплекс-таблица
- Компактное отображение без базисных столбцов
- Дробные значения в читаемом формате
- Названия переменных с индексами
- Строка целевой функции

## 🔬 Алгоритмы

### Симплекс-метод
1. Формирование начальной симплекс-таблицы
2. Проверка оптимальности (все коэффициенты функции ≥ 0)
3. Выбор опорного элемента по правилу минимального отношения
4. Пересчет таблицы методом Жордана-Гаусса
5. Повторение шагов 2-4 до достижения оптимума

### Метод искусственного базиса

**Фаза I:**
- Введение искусственных переменных
- Минимизация суммы искусственных переменных
- Проверка: если сумма = 0, переход к фазе II

**Фаза II:**
- Удаление искусственных переменных
- Решение исходной задачи симплекс-методом
