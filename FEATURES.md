# Реализованные возможности симплекс-метода

## ✅ Основные требования (выполнено 100%)

### 1. ✅ Диалоговый ввод размерности задачи и матрицы коэффициентов
- Ввод количества переменных (2-16)
- Ввод количества ограничений (2-16)
- Ввод коэффициентов целевой функции
- Ввод коэффициентов ограничений в канонической форме
- Выбор типа оптимизации (min/max)
- Все на одном экране для удобства

### 2. ✅ Сохранение и чтение задач из файла
- Сохранение задачи в JSON формат
- Загрузка задачи из JSON файла
- Полное сохранение состояния (включая выбор базиса и настройки)
- Возможность обмена задачами между пользователями

### 3. ✅ Решение задачи с использованием заданных базисных переменных
- Интерактивный выбор базисных переменных (чекбоксы)
- Проверка корректности выбора базиса
- Валидация количества базисных переменных
- Автоматическая инициализация симплекс-таблицы

### 4. ✅ Реализация метода искусственного базиса
- Автоматическое добавление искусственных переменных
- Двухфазный метод решения
- Фаза I: минимизация суммы искусственных переменных
- Фаза II: решение исходной задачи
- Проверка допустимости задачи

### 5. ✅ Автоматический и пошаговый режимы решения
- **Автоматический режим**: полное решение за один клик
- **Пошаговый режим**: контроль каждого шага
- Переключение между режимами одной кнопкой
- Визуализация всех промежуточных шагов

### 6. ✅ Возможность возврата назад в пошаговом режиме
- Кнопка "← Предыдущий шаг"
- Кнопка "Следующий шаг →"
- Счетчик текущего шага
- Полная история всех выполненных шагов
- Навигация по всем этапам решения

### 7. ✅ Выбор опорного элемента в пошаговом режиме
- Автоматическое выделение возможных опорных элементов (синий цвет)
- Клик по ячейке для выбора опорного элемента
- Подсветка выбранного элемента (зеленый цвет)
- Вычисление симплексных отношений для каждого кандидата
- Возможность выбора любого допустимого опорного элемента

### 8. ✅ Работа с обыкновенными и десятичными дробями
- Библиотека Fraction.js для точных вычислений
- Ввод в формате: `1/2`, `-3/4`, `2/3`
- Ввод десятичных дробей: `0.5`, `-0.75`
- Отображение результатов в виде дробей
- Избежание ошибок округления

### 9. ✅ Справка
- Встроенная справка с инструкциями
- Раскрывающийся блок "📖 Справка"
- Описание всех возможностей программы

- Примеры использования

### 10. ✅ Контекстно-зависимая помощь
- Подсказки при наведении на элементы
- Подсветка интерактивных элементов
- Сообщения о текущем состоянии
- Визуальная индикация возможных действий
- Информативные сообщения об ошибках

### 12. ✅ Контроль данных (защита от "дурака")

- Проверка количества базисных переменных
- Проверка допустимости базиса
- Проверка размерности задачи (2-16)
- Информативные сообщения об ошибках с подсказками

## 📊 Технические характеристики

### Алгоритмы
- Классический симплекс-метод
- Метод Жордана-Гаусса для пересчета таблицы
- Правило минимального отношения для выбора опорного элемента
- Двухфазный метод искусственного базиса
- Метод Гаусса с выбором базиса

### Структура кода
- **React Hooks**: useSimplexSolver - вся логика решения
- **Компоненты**: SimplexTable - отображение таблицы
- **Модули**: 
  - SimplexSolver.ts - основной алгоритм
  - ArtificialSolver.ts - искусственный базис
  - Gauss.ts - метод Гаусса
  - types.ts - типы TypeScript
  - utils.ts - вспомогательные функции

### Производительность
- Размерность до 16×16
- Мгновенное решение задач малой размерности
- Быстрое решение задач средней сложности
- Оптимизированные вычисления с дробями
